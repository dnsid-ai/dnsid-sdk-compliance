- **Note (design permits):** `DEFAULT_REGISTRY_URL` is the loopback `dnsid local` registry (`packages/registry/src/index.ts:103`); `createRegistryClientFromEnvironment` (`packages/sdk/src/config-loading.ts:370`) keeps the credential out of loaded configuration and the ordinary constructor reads no environment.

This is design-permitted (zero TTL means single use) but changes deployment performance characteristics relative to the earlier fixed 300-second TTL.

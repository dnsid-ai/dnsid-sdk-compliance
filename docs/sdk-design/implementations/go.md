## Findings

- **Partial — publication snapshot role-host validation:** creation validation delegates to `IdentityConfig.Validate`, which checks HTTPS syntax but not the draft-01 ku/agent and ek/GI host constraints (`registration.go:42`, `identity_manager.go:123`, `:128`). `go run /tmp/dnsid-registration-check.go` reproduced successful creation with `ku=https://other.test/ku` and `ek=https://unrelated.test/ek` for `agent.example.test` / GI `example.test`. Published-record verification remains separate and fail-closed; the setup snapshot should be rejected earlier.
- **Partial — configured signer binding:** `config.Construct` does not check configuration-selected keys against verified local publication (`config/config.go:377`, `:413`). Changing the source can replace the application signer without authorized rotation.
- **Partial — cross-provider rotation/recovery:** one-provider state/options lack saved provider references, current-publication verification, and signer restoration before unpause (`log/c2sptlog/managed_rotation.go:20`, `:67`, `:244`).
- **Partial — onboarding bindings:** `GetOrganizationOnboarding` decodes account/proof fields but does not validate or compare them (`registry.go:879`).
- **Validation limitation — intermittent OIDC test failure:** the first `go test -count=1 ./...` failed `TestOIDC_StrictCompactAndDateBoundaries` at `oidc/boundaries_test.go:34` on the exp=now case. Full rerun and race run passed. The test converts current nanoseconds through float64 seconds (`:31`); the observed boundary failure remains unresolved, not a clean first-run result.
- **Partial — construction ordering:** `config.Construct` (`config/config.go:358`) defers injected-transport conflict checks until `NewIdentityManager` (`identity_manager.go:732`); a `policyUrl` can be fetched first.
- **Partial — unavailable TTL:** `identity_manager.go:349` errors when wire TTL capture is unavailable instead of returning zero for single-operation use, contrary to design `a858525`. Wire capture (`dns_ttl.go:37`) removes the former invented five-minute lifetime; this branch fails closed, not with stale success.
- **Partial — conformance metadata:** empty `KnownDeviations` (`conformance.go:29`) does not declare the unavailable-TTL, publication-snapshot or new provider/account-binding gaps. Passing metadata fixtures do not establish complete declarations.

### Deployment Caveats

- **Managed trust cutover:** development and production pins were replaced without overlap (`log/c2sptlog/managed_verification_registry.go:16`, `:25`, `:64`). Persisted production checkpoint state may reject the replacement tree as rollback; re-baselining must be explicit and audited, never automatic.
- **Registry default:** loopback HTTP is design-permitted (`registry.go:521`); environment loading is explicit (`config/config.go:487`).
- **Hosting:** injected dependencies must honor cancellation and HTTP hosts/custom body readers must impose read deadlines. The synchronous provider API cannot interrupt a blocked custom signer (`OPERATIONS.md:66`).

## Findings

- **Resolved:** the consolidated `Config`/`trustedEntities` contract is implemented; the former `Pre-redesign`/`TBD` rows are superseded by the configuration/acceptance section above.
- **Resolved:** automatic application-profile `logchk` enforcement was removed; callers explicitly request operation evidence (`httpsig/http_signatures.go:383`, `jose/jose.go:264`, `jose/jose.go:502`, `oidc/oidc.go:543`).
- **Note (design permits):** the CLI loader still substitutes `noop:0` for a missing `log_ref` in older CLI configs without `entity_key_path` (`dnsid_config.go:67`); this keeps legacy verification-only configs usable and never applies to publication-capable configs.
- **Validation scope:** `go test ./...`, `go test -race ./...`, the `key/aws` module tests, the 193-expectation shared harness, and the C2SP matrix all passed at the reviewed head; the constructor redesign is cross-cutting, so the shared suites were rerun rather than carried forward.
- **Hosting preconditions:** injected dependencies must honor cancellation; HTTP hosts/custom body readers must impose read deadlines. The synchronous provider API cannot interrupt a blocked custom signer (`OPERATIONS.md:66`).

### Deployment Caveats

- **Managed trust cutover:** development and production pins were replaced without overlap (`dnsid/c2sp_tlog/managed_verification_registry.py:23`, `:33`, `:66`). Persisted production checkpoint state may reject the replacement tree as rollback; re-baselining must be explicit and audited, never automatic.
- **Standalone migration verifier:** without a predecessor resolver it rejects migration genesis (`dnsid/c2sp_tlog/stream_bundle.py:265`, `:398`). Configured readers verify predecessor histories recursively (`tests/test_c2sp_migration.py:388`, `:436`); no new standalone resolver API is required solely to clear this limitation.
- **Package metadata:** checked-in `uv.lock` records the editable package as `0.23.2`, while `pyproject.toml` reports `0.25.0`. Validation used the existing virtualenv without refreshing the lockfile.

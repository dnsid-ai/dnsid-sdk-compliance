## Review scope — 2026-09-22

History was rewritten when the repositories moved from the `Identity-Digital` organization to `dnsid-ai` for public release, so the recorded baselines (`1257fd0` SDK, `1d3fbb5` design) no longer resolve in the current clones. The missing history was obtained from the pre-migration clones: the old `1257fd0` tree differs from the new root commit `c9ae777` ("Initial public release", `0.19.1`) only by organization/URL renames and a `.gitleaksignore`, and the old design `1d3fbb5` differs from the new design root only by tracker/readiness files. The review therefore proceeded incrementally from `c9ae777` (SDK) and `1d3fbb5`-equivalent (design).

Design delta (`1d3fbb5`..`c20013d`, scoped to `docs/sdk-design/` and `fixtures/`): wording only — the `Identity Digital-Managed Trust` heading/anchor became `DNSid-Managed Trust` (already used by this tracker), the C2SP method-spec link became a revision reference, and `fixtures/parse-*.yaml`/`validate.yaml` moved lookalike/unrelated domains to RFC 2606 names with unchanged expectations. No behavior requirement changed; no uncommitted design changes.

SDK delta (`c9ae777`..`4e8c93a`, 22 commits): `25cbc83` adds `run_concurrently`/`BudgetExhausted` and runs the post-`sg` identity branch and the status fetch concurrently with fixed error precedence; `50c3995` additionally preloads the C2SP lifecycle history concurrently with the `ku` fetch; `42c1866`/`f930591` change `register_agent` defaults (production default, `managed` requires `zone_id`, sandbox accepted), make `DEFAULT_REGISTRY_URL` the loopback `dnsid local` registry, skip the credential requirement on loopback, and add `registry_client_from_environment`/`DNSID_API_KEY`; `aa46330` adds an implicit `.test`-TLD private-address exemption to the SSRF allowlist matcher and a `transport_config` option to the C2SP verification factory; the remainder are CI/release/provenance workflows, docs, examples, release-readiness files, and releases `0.19.2`–`0.20.0`. Impacted rows (`VerifyDomain` flow, status fetch, verification budget, `HTTPSFetcher`/SSRF, environment loader, registry client/endpoints, C2SP factory, `VerifiedDomain` construction) were re-reviewed and every citation in a changed file was refreshed; rows whose design text and cited files were both untouched are preserved. Previously recorded gaps (prepared-event `eventId`, OIDC buffered token response, conformance-metadata declarations, issuance-recovery evidence, constructor-time type validation of `identity`/`transport` string fields) are unchanged by this delta and remain open.
